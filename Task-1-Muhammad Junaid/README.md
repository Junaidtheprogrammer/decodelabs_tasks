# Atelier Form

A responsive, mobile-first architecture studio website built with semantic HTML5, modern CSS, and vanilla JavaScript.

## Run locally

Open `index.html` directly in a browser, or serve the folder with any simple static file server.

## Included

- Semantic header, navigation, main sections, articles, form, and footer
- Mobile-first layouts with 768px and 1024px breakpoints
- CSS Grid, Flexbox, container queries, and fluid `clamp()` typography
- Accessible mobile navigation, project filters, saved project state, and form validation
- Reduced-motion support, strong focus states, useful alt text, and live status updates
- Original project-bound hero image
- No frameworks or external runtime dependencies
